# 3. Подсчёт слов в тексте

## Описание задачи

Необходимо реализовать программу, которая анализирует текст и подсчитывает, сколько раз встречается каждое слово.

Например, для строки: "cat dog cat bird dog cat"
результат может быть таким:

- `cat -> 3`
- `dog -> 2`
- `bird -> 1`

Это одна из самых классических задач на использование словаря.

## Обязательная часть

Реализовать:

- чтение строки или текста
- разбиение текста на слова
- подсчёт количества повторений каждого слова
- вывод результата в формате `слово -> количество`

## Вариативная часть

Реализованы следующие задания:

2. **Убирать знаки препинания перед подсчётом** — из слов удаляются точки, запятые, восклицательные знаки, дефисы и другие знаки препинания

3. **Находить самое частое слово** — после подсчёта программа определяет слово (или слова), которое встречается в тексте максимальное количество раз

4. **Выводить только слова, которые встретились больше одного раза** — из результата исключаются слова, встретившиеся единожды

5. **Подсчитывать количество уникальных слов** — программа выводит общее количество различных слов в тексте (без учёта повторений)

## Дополнительная возможность

Программа поддерживает два режима ввода текста для анализа:

- **Чтение с консоли** — пользователь вводит текст вручную после запуска программы
- **Загрузка из файла** — текст для анализа автоматически считывается из заранее подготовленного `.txt` файла

**Выбор режима происходит с помощью консольного меню**
